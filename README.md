# LazyRelay integrations

Public source for the ways to connect to [LazyRelay](https://lazyrelay.com) from your own tools.

| Folder | What it is | Package |
|---|---|---|
| `mcp-server/` | MCP server for AI agents and editors | `@lazyrelay/mcp-server` (npm, MCP Registry) |
| `sdk/` | JavaScript / TypeScript SDK | `@lazyrelay/sdk` (npm) |
| `n8n-nodes-lazyrelay/` | n8n community node | `n8n-nodes-lazyrelay` (npm) |
| `zapier-integration/` | Zapier app definition | Zapier |
| `docs/` | MCP integration notes | |

This repository holds only the integration code. The LazyRelay service itself is not open source.
These folders are kept in step with the private source by a copy step, and the packages are released from here.

Setup guides: https://lazyrelay.com/mcp/ and https://lazyrelay.com/docs
